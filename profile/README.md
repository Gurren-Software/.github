## 🚀 About

GURREN SOFTWARE is a software engineering company building products that matter.

We believe in forward motion. Every line of code, every architecture decision, every deployment pushes us closer to something bigger. We don't just write code. We craft systems that stand the test of time.

---

## 🎯 Mission

To build software that matters. Solutions that are robust, performant, and built to last. We don't settle for "good enough". If it ships under our name, it has to be something we're proud of.

---

## 💎 Core Values

- **Passion**
  This is the fuel. We build because we love building. We take pride in every function, every endpoint, every pixel. That fire is what keeps us moving forward.

- **Impact**
  Code that doesn't solve a real problem is just noise. We focus on creating things that make a tangible difference in people's lives.

- **Integrity**
  We do things right. No cutting corners, no empty promises. Honest communication, transparent decisions, and code we stand behind.

## 🧰 Tools We Love

We don't chase trends. We choose tools that let us execute with precision, move fast, and build systems that last.

- **.NET (C#)** for building robust and high-performance backends
- **Vue.js, Nuxt & Tailwind CSS** for clean, fast, and modern user interfaces
- **PostgreSQL & SQL Server** for solid and reliable data storage
- **Docker** for consistent environments and smooth deployments
- **CI/CD pipelines** for fast, safe, and automated delivery

We favor **clarity over complexity**, **stability over hype**, and **execution over experimentation**.

Technology is never the goal. **Building exceptional software is.**
